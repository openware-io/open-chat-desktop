# gv_chat_desktop 功能实现清单

> 对齐 gv_chat_app（Flutter）已实现功能 1:1 复刻 + 评审通过的高频缺口。状态随开发更新。

## 账号与认证
- [x] 注册 / 登录（用户名+密码，JWT）
- [x] 扫码登录（新增，三端：桌面展示二维码 → App 扫码确认 → 后端会话签发 token）
- [x] 自动登录（token 本地持久化）
- [x] 退出登录（清 token + E2EE 密钥 + WS 关闭）
- [x] 修改密码 / 忘记密码（发邮件）/ 重置密码

## 会话与聊天
- [x] 单聊 / 群聊（文本、乐观发送、chat:ack 回执）
- [x] 会话列表（本地派生，置顶/未读）
- [x] 草稿（P0 缺口，按会话本地保存）
- [x] 已读回执（逐条 chat:read）
- [x] 撤回（chat:recall / recall_notify）
- [x] 离线同步（/messages/sync 游标 + 本地水位）
- [ ] 单会话免打扰（后端 mute 端点已备，conversationId 语义待核对）

## 消息类型
- [x] 文本 / 图片 / 视频 / 语音 / 文件（上传 + 渲染）
- [x] 撤回墓碑渲染

## E2EE 密聊
- [x] 设备密钥注册（X25519，公钥上服务端）
- [x] 密聊建立 / 握手 / 共享密钥派生（无 KDF，字节级对齐 Flutter）
- [x] AES-256-GCM 加密收发（nonce|ciphertext|tag 布局）
- [x] 安全码（SHA-256 前 8 字节大写十六进制）
